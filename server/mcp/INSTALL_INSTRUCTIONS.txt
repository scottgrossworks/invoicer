====================================================================
LEEDZ MCP PLUGIN INSTALLATION GUIDE
====================================================================

WHAT IS THIS?

The Leedz MCP (Model Context Protocol) plugin connects AI chat clients
like Claude Desktop, Claude Code, and LM Studio directly to your local
Leedz database. This lets you explore and analyze your clients and
bookings using natural language in your favorite AI chat interface.

Example: "show me all bookings for John Smith in March 2026"

The plugin exposes 16 tools (list_clients, list_bookings, get_stats,
search_bookings, ...) - the AI you're chatting with picks the right
tool and fills in the arguments itself. No extra API key needed, no
second AI service involved. Your data never leaves your machine.

====================================================================
PREREQUISITES
====================================================================

1. Node.js 18 or later
   - Check: open a command prompt, type "node --version"
   - If not installed: download from https://nodejs.org
   - The plugin has NO other dependencies - it is a single .js file

2. The Leedz Server must be installed and running
   - See the Leedz Server INSTALL_INSTRUCTIONS.txt
   - Verify: open http://localhost:4000/health in a browser -
     you should see {"status":"ok", ...}

3. An AI client that supports MCP (Claude Desktop, Claude Code,
   LM Studio, Codex, ...)

====================================================================
INSTALLATION FOR CLAUDE DESKTOP (Windows)
====================================================================

STEP 1: Locate your Claude Desktop config file:
  C:\Users\<YourUsername>\AppData\Roaming\Claude\claude_desktop_config.json

STEP 2: Open it in Notepad (create it if it doesn't exist)

STEP 3: Add the Leedz MCP server definition (UPDATE THE PATHS):

{
  "mcpServers": {
    "leedz-mcp": {
      "command": "C:\\Program Files\\nodejs\\node.exe",
      "args": ["C:\\path\\to\\Leedz\\mcp\\mcp_server.js"]
    }
  }
}

If the file already has an "mcpServers" object, add the "leedz-mcp"
entry inside it, next to your existing servers.

IMPORTANT PATH NOTES:
- Use DOUBLE BACKSLASHES (\\) in Windows paths
- Point "args" at wherever your mcp_server.js actually lives
  (e.g. C:\\Program Files\\Leedz\\mcp\\mcp_server.js)

STEP 4: Save the file and restart Claude Desktop

STEP 5: Verify - ask Claude:
  "list the first 5 clients from the Leedz"

====================================================================
INSTALLATION FOR CLAUDE CODE
====================================================================

Run this one command in a terminal (adjust the path):

  claude mcp add leedz-mcp -- node "C:\path\to\Leedz\mcp\mcp_server.js"

Then ask Claude Code: "use leedz-mcp to show me this month's bookings"

====================================================================
INSTALLATION FOR LM STUDIO
====================================================================

STEP 1: Open LM Studio, find the Integrations/Program panel
STEP 2: Install > MCP > "Edit mcp.json"
STEP 3: Add the same "leedz-mcp" block shown in the Claude Desktop
        section above, save, and restart LM Studio
STEP 4: Verify - ask: "show me all bookings from the Leedz"

====================================================================
HOW THE PLUGIN WORKS
====================================================================

1. You type a natural language request in your AI client
2. The AI sees the plugin's tool list (each tool documents its own
   filters and fields) and picks the right one - e.g. list_bookings
   with startDateFrom=2026-03-01, startDateTo=2026-03-31
3. The plugin translates that tool call into an HTTP request against
   your LOCAL Leedz server (http://localhost:4000)
4. The Leedz server validates it and runs it against the SQLite
   database
5. Results flow back: Server -> Plugin -> AI -> formatted answer

KEY POINTS:
- The plugin NEVER opens the database file directly - the Leedz
  server is the single gatekeeper for all data operations
- Everything runs on your machine; nothing is sent to the cloud
  (except the optional share_leed tool, which posts to the Leedz
  marketplace when you explicitly ask it to)

====================================================================
AVAILABLE TOOLS
====================================================================

CLIENTS:
  list_clients      search/filter by name, email, company, keyword,
                    date-updated, sort order
  get_client        one client by ID
  create_client     add a client (dedupes by email)
  update_client     change client fields
  touch_client      mark a client processed (by id, name, or email)
  delete_client     PERMANENT delete by ID

BOOKINGS:
  list_bookings     filter by client name/email/ID, status, and
                    date range; results include full client details
  get_booking       one booking by ID
  search_bookings   keyword search (title/description/notes/location)
  create_booking    add a booking (auto-creates the client if needed)
  update_booking    change booking fields
  delete_booking    PERMANENT delete by ID

ANALYSIS / META:
  get_stats         system-wide counts and totals
  get_client_stats  aggregate client statistics
  health            is the server up + which database file

MARKETPLACE:
  share_leed        post a leed to the Leedz marketplace (AWS)

====================================================================
SAFETY AND SECURITY
====================================================================

1. THE PLUGIN HAS FULL DELETE PERMISSIONS
   - delete_client / delete_booking are permanent, no undo
   - Verify before confirming destructive operations

2. THE PLUGIN CAN MODIFY ALL DATA
   - Updates are immediate and only reversible from backup

3. API GATEKEEPER PROTECTION
   - The Leedz server validates every request (required fields,
     formats) before anything touches the database

4. BACKUP RECOMMENDATION
   - Regularly copy your database file (data/leedz.sqlite in your
     Leedz folder) to a safe location

====================================================================
TROUBLESHOOTING
====================================================================

PLUGIN NOT SHOWING IN AI CLIENT:
- Config paths must use double backslashes: C:\\path\\to\\file
- Check Node.js: "node --version" (must be 18+)
- Restart the AI client after editing its config

"CANNOT REACH LEEDZ SERVER" ERRORS:
- Verify the Leedz server is running (system tray icon)
- Test: open http://localhost:4000/health in a browser
- If your server uses a different port, edit
  mcp_server_config.json > database.apiUrl to match

UNEXPECTED RESULTS:
- Check mcp_server.log next to mcp_server.js
- Check the Leedz server's server.log for API errors

====================================================================
CONFIGURATION (ADVANCED)
====================================================================

CONFIG FILE: mcp_server_config.json (next to mcp_server.js)

- database.apiUrl   URL of your Leedz server
                    (default: http://localhost:4000)
- aws.*             marketplace credentials for the share_leed tool
                    (optional - all other tools work without it)
- logging.file      log file path (default: ./mcp_server.log)

No API key is required - the plugin does not call any LLM itself.
