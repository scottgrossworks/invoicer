====================================================================
LEEDZ SERVER - INSTALL, CONFIGURE & RUN
====================================================================

!!! TO DO FIRST !!!
--------------------------------------------------------------------
server_config.json ships with a PLACEHOLDER database path. The server
will NOT start until you edit it. After extracting (Step 1), open
server_config.json in Notepad and set:

    "url": "file:./data/leedz.sqlite"

That file - server\data\leedz.sqlite - IS your business. Every client
and booking you save lives there, on your machine and nowhere else.
Back it up by copying that one file somewhere safe.

To run a second business or a test set, point "url" at a different
filename in the same data\ folder and restart. The Chrome extension's
Startup page shows which database is currently connected.

Also fill in the two Chrome extension files before first use -
DOCS\VALUE_PROP.md (describe your business in plain English) and
LLM_KEY.json (your AI key). See the extension's
INSTALL_INSTRUCTIONS.txt, section TO DO FIRST.
--------------------------------------------------------------------


--------------------------------------------------------------------
STEP 1: DOWNLOAD AND EXTRACT
--------------------------------------------------------------------
1. Download "leedz-server-win-x64.zip" from theleedz.com
2. Right-click the ZIP file and select "Extract All..."
3. Choose a permanent location (like C:\Program Files\Leedz)
   IMPORTANT: Don't delete this folder after installation - this is
   where your database and settings are stored!
4. Click "Extract"

You should see a folder containing:
  - TheLeedz.exe           (THE APP - double-click this one)
  - leedz-server.exe       (Backend server - started FOR you, never click)
  - server_config.json     (Server settings)
  - prisma/ folder         (Database schema)
  - data/ folder           (Your database files)
  - mcp/ folder            (Gmail sending + Claude/AI support)
  - img/ folder            (Icons)

--------------------------------------------------------------------
STEP 2 (OPTIONAL): INSTALL NODE.JS FOR GMAIL SENDING
--------------------------------------------------------------------
Skip this step if you don't need the Chrome Extension's Outreach page
to send email through your Gmail account - everything else works
without it.

1. Download and install Node.js (LTS) from https://nodejs.org
2. Use the default install options

--------------------------------------------------------------------
STEP 3: START THE SERVER
--------------------------------------------------------------------
1. Double-click "TheLeedz.exe" (the green grass icon)
2. A small icon appears in your Windows system tray (bottom-right,
   click the ^ arrow if you don't see it)
3. That's it. The server (and Gmail support, if Node.js is installed)
   start automatically in the background - no windows open.

The tray icon is your control panel: right-click it for Start Server,
Stop Server, Configure, and Exit. A green dot in the menu header means
the server is running; red means stopped.

--------------------------------------------------------------------
STEP 4: CONNECT YOUR CHROME EXTENSION
--------------------------------------------------------------------
Now install the Leedz Chrome extension (see separate instructions).
On the Chrome Extension's Startup page, open the "Leedz Config"
section and enter:
  - Server Host: localhost
  - Server Port: 4000
  - MCP Host: localhost
  - MCP Port: 7000   (only needed for Gmail sending)

When connected, the Database Name will appear on the Startup page.


====================================================================
STOPPING AND RESTARTING
====================================================================

TO STOP: Right-click the tray icon and select "Stop Server" (or "Exit"
to also close the tray)

TO RESTART: Double-click "TheLeedz.exe" again (or right-click the tray
icon and select "Start Server")

TO AUTO-START ON WINDOWS BOOT (Recommended):
1. Right-click the Leedz tray icon
2. Select "Settings"
3. Check the box: "Start TheLeedz automatically when Windows starts"
4. Click "Save"

Now Leedz will automatically start every time Windows boots!


====================================================================
CONFIGURATION
====================================================================

CHANGING THE SERVER PORT:
If port 4000 is in use by another program, change it:
1. Open "server_config.json" in any text editor (Notepad works)
2. Change the "port" number to any available port (e.g., 4001)
3. Save the file and restart the server
4. Update your Chrome Extension Startup page to use the new port

CHANGING THE GMAIL MCP PORT:
1. Open "mcp\gmail_mcp_config.json" in any text editor
2. Change the "http.port" number to any available port
3. Save the file and restart the server
4. Update your Chrome Extension Startup page's MCP Port to match

SERVER LOG:
The server writes a log file to "server.log" in the same folder.
If something isn't working, check this file for error messages.


====================================================================
DATABASES
====================================================================

Your data is stored in a SQLite database file inside the data/ folder.
By default: data\leedz.sqlite

SWITCHING DATABASES:
You can maintain multiple databases (one per business, or a test DB):
1. Open "server_config.json" in a text editor
2. Change the "url" value under "database" to point to your file:

   "database": {
     "type": "prisma_sqlite",
     "url": "file:./data/my_other_business.sqlite"
   }

3. Save the file and restart the server
4. The Chrome Extension Startup page will show the new DB name

BACKING UP YOUR DATABASE:
To back up your data, simply copy the .sqlite file from the data/
folder to a safe location. To restore, copy it back.

STARTING FRESH:
1. Stop the server
2. Delete (or rename) the current .sqlite file in data/
3. Copy the original leedz.sqlite from a backup or re-extract the ZIP
4. Restart the server

EXPORTING DATA:
Open these URLs in your browser while the server is running:
  - http://localhost:4000/api/dump/clients   (export all clients)
  - http://localhost:4000/api/dump/bookings  (export all bookings)
  - http://localhost:4000/api/dump/config    (export configuration)

Files are saved to an exports/ folder with timestamps.


====================================================================
TROUBLESHOOTING
====================================================================

PORT ALREADY IN USE: If you see "Port 4000 is already in use",
another program is using that port. Either stop that program or
edit server_config.json to change the port number.

FIREWALL WARNING: Windows may ask to allow network access. Click
"Allow access" - the server only runs locally on your computer.

SERVER WON'T START: Make sure you extracted ALL files from the ZIP.
Try running as Administrator (right-click TheLeedz.exe, select
"Run as administrator"). Check server.log in the Leedz folder for
error messages.

GMAIL AUTH BUTTON STAYS DISABLED: The Gmail MCP did not start.
Confirm Node.js is installed (Step 2), then right-click the tray
icon, Stop Server, Start Server.

EXTENSION CAN'T CONNECT: Right-click the tray icon - the menu header
dot should be green. Make sure the port in the Chrome Extension's
Startup page matches server_config.json.

DATABASE ISSUES: Your database is stored in data\leedz.sqlite.
To backup your data, copy this file to a safe location.

====================================================================
SYSTEM REQUIREMENTS
====================================================================
- Windows 10 or later (64-bit)
- .NET 8 Runtime (usually pre-installed on modern Windows)
- Node.js LTS (only required for Gmail sending - see Step 2)
- Port 4000 available (or configure a different port)
- Port 7000 available (only required for Gmail sending)
- 50 MB disk space
