====================================================================
LEEDZ CHROME BROWSER EXTENSION INSTALLATION GUIDE
====================================================================

12/2025: These instructions are temporary, until the Leedz is 
registered with Google and available on the App Store.  Then the 
install will be easier, but the program will be harder to update.  
While the app is in beta, and we are taking your feature requests 
and bug reports please endure this more cumbersome process.

Email: theleedz.com@gmail.com

--------------------------------------------------------------------
STEP 1: DOWNLOAD AND EXTRACT
--------------------------------------------------------------------
1. Download the file "leedz-chrome-ext.zip"
2. Right-click the ZIP file and select "Extract All..."
3. Choose a permanent location (like your Documents folder)
   IMPORTANT: Don't delete this folder after installation - the
   extension needs it to work!
4. Click "Extract"

--------------------------------------------------------------------
STEP 2: OPEN CHROME EXTENSIONS PAGE
--------------------------------------------------------------------
1. Open Google Chrome browser
2. In the address bar, type: chrome://extensions
3. Press Enter

--------------------------------------------------------------------
STEP 3: ENABLE DEVELOPER MODE
--------------------------------------------------------------------
Look for a toggle switch labeled "Developer mode" in the top-right
corner. Click it to turn it ON (it should turn blue).

--------------------------------------------------------------------
STEP 4: LOAD THE EXTENSION
--------------------------------------------------------------------
1. Click the "Load unpacked" button (appears after Developer mode)
2. Browse to the folder you extracted in Step 1
3. Select the folder and click "Select Folder"
4. The Leedz extension will appear in your extension list

--------------------------------------------------------------------
STEP 5: START USING LEEDZ
--------------------------------------------------------------------
Look for the Leedz icon in your Chrome toolbar (top-right). Click it
to open the sidebar.

--------------------------------------------------------------------
STEP 6: CONFIGURE THE STARTUP PAGE
--------------------------------------------------------------------
The sidebar opens on the Startup page. Before using Leedz you must
connect it to your Leedz Server (see the Leedz Server install guide)
and enter your LLM provider key. See README.md, section STARTUP, for
what to enter and where.


====================================================================
TO DO FIRST - FILL THESE IN
====================================================================

Two files in this folder decide whether Leedz works for YOUR
business. Fill them in now - the extension will not run correctly
until you do. (A third file, the server's database path, is covered
in the Leedz Server install guide.)


1. DESCRIBE YOUR BUSINESS  ->  DOCS\VALUE_PROP.md
--------------------------------------------------------------------
This is the most important file in the product. Open it in Notepad
and write, in PLAIN ENGLISH, who you are and what you sell.

The AI reads this on every single parse. It is how the extension:
  - tells YOUR contact details apart from a client's
  - prices a booking and fills in the invoice header
  - writes outreach and replies that sound like you
  - knows whether a job is inside your service area

REQUIRED - the extension will not start without these:
  Trade, Product Name, Seller, Email, Phone

OPTIONAL but strongly recommended - the more you write, the better
every draft gets:
  Website, Socials, Geography / service area, rates and pricing,
  what you provide, terms, and the bank details that appear on
  your PDF invoices.

Write it like you would explain your business to a new employee.
Vague file in, vague emails out.


2. PASTE YOUR LLM KEY  ->  LLM_KEY.json
--------------------------------------------------------------------
The whole file is one line:

  { "api-key": "sk-ant-PASTE-YOUR-KEY-HERE" }

Replace the placeholder with a real key from any provider (Claude,
ChatGPT, OpenRouter, or a local model). Nothing that needs AI -
parsing, drafting, invoices - works until this is set.


3. YOUR DATABASE  ->  (in the Leedz Server folder)
--------------------------------------------------------------------
Everything you save lives in ONE file on your own machine:

  server\data\leedz.sqlite

Back it up by copying that file somewhere safe. To run a second
business or a test set, point "database.url" in server_config.json
at a different filename and restart the server. The Startup page
shows which database is currently connected.

NOTE: server_config.json ships with a PLACEHOLDER database path.
You must edit it before the server will start. See the Leedz Server
INSTALL_INSTRUCTIONS.txt.

TROUBLESHOOTING
====================================================================

SECURITY WARNING: Chrome will show a warning that this extension is
not from the Chrome Web Store. This is normal for business software

EXTENSION DISABLED: If Chrome disables the extension after an update,
simply return to chrome://extensions and re-enable it.
